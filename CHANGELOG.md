# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-10-28

### Added

- Inventory system: backpack, hotbar, slot management and item drag and drop.
- Fishing minigame with catch UI.
- Game time, day progress, seasons and the calendar journal.
- NPC dialogue system with dialogue triggers.
- Save and load to `save.json` in `Application.persistentDataPath`.
- Player movement, tool usage and camera follow.
- Items defined as ScriptableObjects in `Assets/_Project/Resources/Items`.
